# learn

## The problem

You need to understand a technical concept well enough to make product decisions about it, but most explanations are either one sentence or a full course. You want the middle: enough to reason about trade-offs, no more.

## What it does

Explains one concept at the 80/20. Plain language first, then the term, grounded in a real example from whatever you are working on. It stops shallow and asks before going deeper, so you control the depth.

## How it behaves

- Answers in a fixed five-part format: one-liner, why it matters, how it works, a real example, an offer to go deeper.
- Defines jargon inline rather than assuming it.
- Keeps each answer short.

## Use it

Copy `learn.md` into `~/.claude/commands/` and call `/learn <concept>`.
