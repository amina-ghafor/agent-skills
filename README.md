# claude-code-skills

A set of Claude Code commands I use as a PM. Each is a single prompt file that does one job: think a problem through, explain something, draft in a particular voice, review a piece of work.

Drop a skill's `.md` file into your Claude Code commands directory (`~/.claude/commands/`) and call it as `/name`. Each folder has its own README with the problem it solves and how it behaves.

## Skills

| Skill | What it does |
| --- | --- |
| [learn](learn/) | Explains a technical concept at the 80/20, pitched at a non-engineer |
| [debate](debate/) | Stress-tests a plan by questioning it, one point at a time, before you commit |

More arrive one at a time.
